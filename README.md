# About - Mon Feb 16
I used claude to generate a boilerplate repo based on some existing projects I have created. It 
still includes artifacts from some of those projects that I may remove.

The intent is for simple, modular, minimal dependency vanilla web components that are designed to 
be used in markdown files. This means that they should be readable in plain markdown with 
descriptive names and properties or slots that make sense.

I do not intend to put further work into this repo until I am actually creating one of these
components, at which point I will update this boilerplate to match my design principles
